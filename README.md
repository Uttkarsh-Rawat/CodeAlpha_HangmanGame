# 🎮 Hangman Game – CodeAlpha Internship

## 📌 Project Description

Hangman Game is a simple text-based word guessing game
developed using Python.

In this game, the computer randomly selects a word from
a predefined list of five words. The player has to guess
the word by entering one letter at a time.

The player gets a maximum of 6 incorrect guesses.

## ✨ Features

- Random word selection.
- Five predefined words.
- User-friendly console interface.
- Maximum 6 incorrect attempts.
- Displays correctly guessed letters.
- Win and Game Over messages.

## 🛠️ Technologies Used

- Python
- Random Module
- While Loop
- For Loop
- If-Else Statements
- Lists and Strings

## 💻 Requirements

- Python 3.x
- VS Code or any Python IDE.
